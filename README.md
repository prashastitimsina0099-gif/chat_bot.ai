# Rule Based Chatbot using Python

## Description
A simple rule based chatbot using python to reply user messages according to predefined rules and keywords. The chatbot is capable of carrying out basic conversations, answering questions, and exiting the conversation when the user says `bye`.

## Features
- Basic chat or conversation
- Answer some questions
- Reply with unknown message for undefined or unknown inputs
- Exit or quit the conversation
## Languages and Frameworks

- Python 

## How To Run
1. Install Python 
2. Clone or download this repository from GitHub
3. Open the terminal in the project folder
4. Execute this command
```bash

python expert_chatbot.py
```

## Project File
- `expert_chatbot.py`: Python file containing the full code of this project

## Objective
This project is created to gain knowledge on Python programming, condition statements, loops, rule based chatbot.
